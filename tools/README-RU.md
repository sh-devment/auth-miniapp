## auth-miniapp

Вход в экосистему через Telegram.

## Две задачи

1. **Бесшовная авторизация** — подхватывает учётные данные пользователя из
   Telegram, так что войти можно без лишних шагов
2. **menu внутри Telegram** — раз сессия получена так легко, menu открывается
   прямо как мини-апп, и переходы между сервисами вообще незаметны
